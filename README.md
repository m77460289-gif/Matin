# کنکور کامپیوتر | نسخه وب

وب‌اپلیکیشن فارسی و راست‌چین برای برنامه‌ریزی و پیگیری مطالعه داوطلبان رشته شبکه و نرم‌افزار رایانه.

## اجرای آنلاین

پس از فعال‌سازی GitHub Pages و تکمیل اولین انتشار، سایت از نشانی زیر در دسترس خواهد بود:

`https://m77460289-gif.github.io/kunkor/`

## امکانات

- داشبورد با هدف روزانه و فعالیت‌های اخیر
- ثبت جلسه مطالعه و گزارش زمان
- فهرست کتاب‌ها و پیگیری پودمان‌ها
- تایمر تمرکز با بازیابی زمان پس از تازه‌سازی صفحه
- آزمونک پنج‌سؤالی و آزمون تمرینی ده‌سؤالی
- مرور فاصله‌دار لایتنر با کارت‌های شخصی
- یادداشت‌ها و دفترچه اشتباهات
- گزارش پیشرفت و عملکرد
- تعیین تاریخ هدف و برنامه مسیر مطالعه
- گزارش همراه
- خروجی و بازیابی پشتیبان JSON
- نصب به‌عنوان وب‌اپ روی موبایل و پوسته آفلاین

## ذخیره‌سازی و حریم خصوصی

اطلاعات این نسخه در `localStorage` مرورگر ذخیره می‌شود و به سرور ارسال نمی‌شود. پاک‌کردن داده‌های مرورگر یا استفاده از دستگاه/مرورگر دیگر ممکن است اطلاعات را از دسترس خارج کند؛ بنابراین از بخش پشتیبان‌گیری، مرتب فایل JSON دریافت کن و در جای امن نگه دار.

این نسخه فعلاً تک‌کاربره و بدون حساب کاربری یا همگام‌سازی ابری است. برای استفاده روی چند دستگاه باید قابلیت همگام‌سازی و احراز هویت جداگانه طراحی شود.

## انتشار با GitHub Pages

Workflow موجود در `.github/workflows/release.yml` پس از push به `main`، فایل‌های وب را اعتبارسنجی و روی GitHub Pages منتشر می‌کند.

در تنظیمات مخزن، بخش **Settings → Pages** را باز کن و در قسمت **Build and deployment**، گزینه **Source: GitHub Actions** را انتخاب کن. پس از موفقیت workflow، آدرس سایت در بخش Deployments و خروجی workflow نمایش داده می‌شود.

## ساختار

- `index.html` — پوسته و ساختار رابط
- `style.css` — طراحی واکنش‌گرا و راست‌چین
- `app.js` — امکانات و منطق برنامه
- `manifest.webmanifest` و `sw.js` — نصب‌پذیری و کش آفلاین
- `icon.svg` — آیکون وب‌اپ

## نکته محتوایی

عنوان پودمان‌ها در نسخه وب، دسته‌بندی اولیه برای برنامه‌ریزی هستند؛ پیش از استفاده آموزشی، آن‌ها را با فهرست چاپ کتاب‌های رسمی سال تحصیلی خود تطبیق بده.
